Voice Translator

English ↔ Tamil voice translation with speech recognition, translation and text-to-speech — built as a practical mobile application using visual programming.

Explore Project GitHub README

🎙️ Project Overview

Voice Translator lets a user select English or Tamil, speak into the microphone, translate the recognized sentence and hear the translated result. The project demonstrates how multiple MIT App Inventor components can be connected using event-driven blocks.

SpeechRecognizerTranslatorTextToSpeechAndroidMIT App Inventor

✨ Features

🇬🇧 English → TamilRecognize English speech and translate it to Tamil.
🇮🇳 Tamil → EnglishRecognize Tamil speech and translate it to English.
🎤 Voice InputUse the phone microphone for hands-free input.
🌐 TranslationSend recognized text to the Translator component.
🔊 Voice OutputSpeak the translated result using TextToSpeech.
🧩 Block ProgrammingBuilt with beginner-friendly event-driven logic.

🛠️ Tech Stack

Platform: Android

Tool: MIT App Inventor

Components: SpeechRecognizer, Translator, TextToSpeech

🧠 Logic

Select language ↓ Speech recognition ↓ Recognized text ↓ Check selected language ↓ Translate ↓ Display result ↓ Speak translation
